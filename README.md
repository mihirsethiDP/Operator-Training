# Operator Training — Chapter 1: Water Parameters & On-site Water Testing

Interactive, voice-narrated training module for STP/ETP operators (English / Hindi).
Narration is pre-recorded with Sarvam AI Bulbul v3 (speaker "ritu") and plays from `audio/<lang>/`.

- `index.html` — the module (Learn tab: 15 scenes with checkpoints and a final quiz; Video script tab: avatar + localization production pack)
- `audio/hi/`, `audio/en/` — one MP3 per spoken line, mapped by `manifest.json`

Open the GitHub Pages URL on a phone; tap a language to start.
